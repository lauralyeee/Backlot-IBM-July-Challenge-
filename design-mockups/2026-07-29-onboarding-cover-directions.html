Onboarding cover — working comparison

Three directions, same design system

All three reuse your actual tokens: Barlow Condensed / Inter, the monochrome palette, the aperture mark, and the filmstrip + slate-number classes already sitting unused in global.css. Copy below is a first pass, not final. The brand name shown is a placeholder ("Backlot") to test how a real name would sit in the layout, not a decision.

01

Refined split screen

Low effort · same layout

Keeps your current two-column shell. Fixes the part that actually reads as generic: a vertical list of five identical icon+title+text rows. Grouping them 2-up breaks the "AI SaaS feature list" rhythm, and a faint radial highlight behind the headline replaces the flat gradient.

02

Filmstrip reel

Medium effort · leans on motifs already in your CSS

Drops the split screen. Full-width hero, then the five capabilities run as a horizontal reel, slate-numbered like film frames (01–05), using the .filmstrip-divider / .slate-number classes that already exist in global.css but aren't used anywhere yet. This is the option that looks least like a template, because the motif is yours, not a generic icon-list.

03

Single column, top stepper

Higher effort · restructures the wizard shell

No pitch panel at all. The wizard is the whole screen, centered, with a thin segmented bar up top instead of a sidebar-style column. Capabilities move behind a "see what it does" pill so they don't compete with the step you're actually on. Reads closer to Linear or Notion's setup flow than a marketing template. Best fit if you have time before the 31st to touch the layout, not just the copy.
